# S04 — ESCO API and taxonomy

- Publisher: European Commission, ESCO.
- URL: https://esco.ec.europa.eu/en/about-esco/escopedia/escopedia/esco-api
- Type/assessment: official taxonomy/API documentation; high credibility and current; EU-oriented concepts.
- Short evidence excerpt: ESCO provides both a “web-service API” and a “Local API.”
- Relevance: a downloadable/local taxonomy makes an offline workflow technically possible. API software licensing and taxonomy data reuse/redistribution are separate questions.
- Use in this project: prefer a local frozen taxonomy version with URI/provenance and check the dataset's own reuse terms before bundling. Do not call the online API with challenge records.
