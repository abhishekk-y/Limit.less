## Operational rules

- Never mix fictional catalog records with provider or public-source observations.
- Keep the Adzuna shared counter persistent in the database; each retry consumes budget. Search is enabled only after account-level or server-side credentials are configured.
- Preserve each employer posting URL, first-seen time, most-recent check time and provider identity. Similar title/company/description matches are marked as possible duplicates for human review; never silently suppress them or claim confirmed reposts.
- Treat missing posting fields as unknown. An eligibility result is a guide, not an official decision. Use notice-specific age cutoffs and relaxation values when available, and show a verification note for defaults.
- Government notification extraction must validate the official source, preserve its notice URL, and pass through human review before publication. It must remain disabled while robots/access terms are unverified.
- Do not crawl LinkedIn, Naukri, Indeed, or third-party government-job aggregators.
