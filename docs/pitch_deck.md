# SkillSetu X: Pitch Deck Outline

1. **The Problem**: Education is disconnected from real-time job market requirements.
2. **The Solution**: SkillSetu X - A deterministic, graph-based intelligence engine mapping skills to opportunities.
3. **How It Works**:
   - NLP Extraction
   - Graph Traversal (NetworkX)
   - Match Scoring (STS, CDS, SOE)
4. **Market Opportunity**: Millions of graduates needing career navigation.
5. **Competitive Advantage**: Deterministic matching (no LLM hallucinations), transparent metrics (Lineage).
6. **Traction**: Demo personas, robust test coverage.
7. **The Team**: Senior Data Scientists & ML Engineers.
