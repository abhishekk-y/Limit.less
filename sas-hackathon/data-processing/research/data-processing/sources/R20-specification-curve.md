# R20 — Specification curve analysis

- **Source:** Simonsohn, U., Simmons, J. P. & Nelson, L. D. (2020), *Specification curve analysis*, Nature Human Behaviour.
- **Type:** Peer-reviewed statistical-method paper.
- **URL:** https://www.nature.com/articles/s41562-020-0912-z
- **Credibility / recency / bias:** 5 / 3 / 2. Methods paper; requires appropriate specification generation and inference.
- **Finding used:** Displaying the distribution of estimates across defined analytic choices makes researcher flexibility visible.
- **Design implication:** A later Limit.less sensitivity view should list each executed scenario and the corresponding rate/rank, plus the rule changes that produced it. The current SAS run only has descriptive sensitivity views, not a complete specification-curve test.
- **Limit:** Do not call a rank comparison a formal specification-curve analysis unless the full method is implemented and reviewed.
