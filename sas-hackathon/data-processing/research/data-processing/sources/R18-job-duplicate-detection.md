# R18 — Duplicate job-posting detection

- **Source:** *Combining Embeddings and Domain Knowledge for Job Posting Duplicate Detection* (2024).
- **Type:** Research preprint.
- **URL:** https://arxiv.org/abs/2406.06257
- **Credibility / recency / bias:** 3 / 4 / 3. Recent preprint; methods depend on data and labels and require local verification.
- **Finding used:** Duplicate detection can combine lexical/character overlap, semantic representations and domain knowledge rather than rely on one similarity signal.
- **Design implication:** Current SAS work only uses exact normalized-text fingerprints for a transparent sensitivity diagnostic. Semantic clustering is future work requiring a locally reviewed pair benchmark, threshold selection and false-merge/false-split analysis.
- **Limit:** No semantic duplicate model is implemented or evaluated in this project at this time.
