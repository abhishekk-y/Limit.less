# Verification layout

- `api/`: account scope, uploads, resume extraction, providers, source modes, job imports, local worker and receipt behavior.
- `scoring/`: scoring and eligibility calculations.
- `skillgraph/`: extraction and normalization behavior.
- Web browser journeys: `apps/web/e2e/`.

Controlled employer pages and synthetic screenshots verify mechanisms. They do not prove compatibility with every employer, live LinkedIn publication or SAS execution. Current delivery results are in `docs/verification/local-delivery.md`.
