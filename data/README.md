# Data layout

`seed/` contains fictional demonstration inputs and curated reference tables. They are separate from live employer data and from the private account database.

Live-feed summaries are in `docs/evidence/`; public receipt files contain source URLs, collection timestamps, counts and selected public listing links. They contain no applicant resumes or provider credentials.

The supplied challenge source files are not part of the public release. Recorded aggregate demonstrations and their limitations are documented in `docs/research/data-evidence.md`. Raw workbooks, archives and local extraction files are excluded from Git.
